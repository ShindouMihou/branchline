Keep Branchline approvals focused on Git and GitHub, with a cleaner Changes toolbar.

### Git/GitHub-only approval guidance

- Scope managed skills, injected Codex/Claude reminders, MCP initialization instructions, tool descriptions, and capabilities explicitly to consequential Git/GitHub effects.
- Route unrelated services such as Convex, databases, deployments, and cloud administration through their normal tools and permissions, even for remote or sensitive operations.
- Classify scripts and aliases by their effects. Inspect or clarify unknown commands instead of using Branchline as a general approval fallback.
- Preserve direct execution for read-only queries, safe local Git work, and disposable isolated fixture tests.
- Preserve whole-command approval for Git/GitHub workflows. Clarify user-supplied chains mixing gated Git/GitHub actions with unrelated service mutations before splitting or changing them.
- Update previously installed, unchanged managed skills and opted-in instruction blocks automatically. Customized or unowned content is preserved.

These are agent-routing instructions. The shell executor does not statically sandbox arbitrary scripts or independently verify all effects.

### Cleaner Stash changes placement

- Move Stash changes into the file-filter row as a compact archive button.
- Remove the extra toolbar row, align control heights, and keep an accessible name and tooltip.

### Update

Choose **Branchline → Check for Updates…**, then **Install & restart**. Automatic checks remain quiet unless an update is available. Restart existing AI sessions and reconnect their MCP connection after updating to load the new guidance and tool descriptions.

For a fresh installation:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.
