Save work for later, review your stashes, and keep AI approvals focused on consequential Git actions.

### Stash management

- Save all changes, selected files, or only unstaged changes while keeping staged work ready to commit, including partially staged files.
- Opt in to new, untracked files. Ignored files stay excluded.
- Browse stashes by name, branch and date; review saved changes and staging with syntax-highlighted diffs and supported image previews.
- Apply or Pop with an optional staging restore. Pop removes a stash only after a successful restore; conflicts keep the stash available.
- Confirm deletion and retain local recovery references. Detect stale files, branch changes and shifted stash selections before acting.
- Capture both sides of selected-file renames without saving unrelated staged work.

### More focused AI approvals

- Run read-only queries, builds, isolated fixture tests and safe local operations directly.
- Keep Branchline approval for commits in real repositories, pushes, PR/GitHub changes, destructive actions, history rewrites, and authentication/security or publication-destination changes.
- Preserve whole-command approval for chains containing a gated action, and keep waiting for the actual result. A timeout never grants approval.
- Update previously installed, unchanged managed skills and opted-in instruction blocks automatically. Customized or unowned instructions are preserved.

### Preview regression coverage

- Verify that guarded release chains keep their Stage, Commit, Push and Release cards, even after shell checks and substitutions. The current syntax parser handles this case; older installed apps need the update.

### Clearer Changes sections

- Make the entire Staged and Unstaged heading clickable to collapse or expand its files.
- Keep the chevron, file count and accessibility state consistent, preserve keyboard focus, and retain collapsed state during refreshes.

Stash renaming, ignored-file inclusion, and saving changes inside submodules remain outside this workspace's current support.

### Update

Choose **Branchline → Check for Updates…**, then **Install & restart**. Automatic checks remain quiet unless an update is available. Restart existing AI sessions to load updated guidance.

For a fresh installation:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.

Validated with 205 Rust tests, 78 frontend tests, 11 offline installer checks, 2 release-manifest checks, and the production build.
