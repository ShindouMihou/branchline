Clearer pull request updates and a lighter release workflow.

### Pull request edit previews

- Recognize `gh pr edit` and show its PR number, URL or branch target, explicit repository, new title, requested base change, and description.
- Render supplied `--body-file -` / `-F -` input as Markdown for a single literal GitHub command. Empty input is distinct from missing input.
- Preserve exact whole-command approval. Shell chains, pipelines and redirects do not claim that the supplied input reaches the PR unchanged.
- Keep large descriptions out of the structured Markdown preview above 64 KB; the full command input remains available for inspection.
- Display only requested edit fields, without inventing a source-branch change or fetching the existing PR.

### Consistent standard-input design

- Replace the plain browser disclosure with an icon-led row matching the request cards.
- Label recognized PR descriptions as Description input, with character count and access to the exact raw text.
- Keep generic input escaped, readable, keyboard-accessible, and collapsed by default. Activity receipts continue to omit raw stdin.

### Automatic build-cache cleanup

- Clean generated Rust debug and compiler caches after successful release preparation, retaining the app bundle, release assets, source and toolchain.
- Check matching release metadata and ZIP checksum before cleanup. Refuse linked cache paths, overlapping output folders, and active Rust builds.
- Provide `npm run release:cleanup` to retry cleanup if another build prevented it.
- Expect the next Rust build to take longer while caches regenerate.

### Update

Choose **Branchline → Check for Updates…**, then **Install & restart**. Automatic checks stay quiet unless an update is available.

For a fresh installation:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.

Validated with 219 Rust tests, 87 frontend tests, 8 release-manifest and cleanup checks, 11 offline installer checks, 8 MCP protocol cycles, and the production build. Cleanup was checked against a retained app and all five release assets without changing their bytes.
