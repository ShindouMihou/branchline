Optional auto-approval and a calmer AI workspace.

### Approve your way

- Manual approval remains the default for existing and new installations.
- Opt into selected actions or broader session approval for one AI connection. Selected actions include staging files, ordinary commits, explicit branch pushes, and pull request creation or title/description edits.
- Choose the current repository, browse for another local repository, or explicitly cover all repositories for the selected connection.
- Review the scope and duration before enabling a rule. Rules expire after 15, 30 or 60 minutes, or when Branchline quits. Pause all or remove a rule at any time.
- Whole requests are authorized together. Unsupported or dynamic command syntax still asks for manual review under selected-action rules. Broad session approval can authorize destructive commands and scripts; repository scope is a starting context, not a sandbox.
- Preserve execution checks, preview revalidation and audit receipts. Automatic approval is recorded separately from manual approval and never implies command success. MCP clients cannot create or widen rules.

### Cleaner AI settings

- Compact connection rows open focused connection settings, with the full setup row clickable and disconnect actions tucked into a menu.
- A two-step Add rule flow separates action selection from scope review and explicit consent.
- Content-sized settings and confirmation dialogs, consistent dropdown spacing, and readable dark dropdown options.
- Clearer Desktop notifications wording and quieter descriptive text throughout.

### Simpler skills setup

- Install or update skills for all detected, supported AI clients with one action. Instruction reminders have their own install-for-all action.
- Compact rows, subtle Installed badges, detected-client names and one collapsed details section replace per-client installation choices.
- Preserve custom instruction content and conflicting files. Show conflicts for manual attention rather than overwriting them.
- Connection onboarding uses the same all-client installation approach. Skills and reminders guide AI behavior; they grant no Git permissions.

### Update

Choose **Branchline → Check for Updates…**, then **Install & restart**. Automatic checks stay quiet unless an update is available. After updating, start a new AI session to load updated guidance.

For a fresh installation:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.
