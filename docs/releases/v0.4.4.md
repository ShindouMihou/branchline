Update checks now stay out of your way unless a new version is available.

### Improvements

- Open the updater prompt only when an update is available. Checking, up-to-date results, and connection errors no longer open an updater modal.
- Show a brief nonmodal result for manual checks. Automatic checks remain quiet.
- Keep the automatic-check switch and manual check action directly in **Appearance → App updates**.
- Handle delayed and cross-window check results without opening stale prompts.

Signed downloads and explicit **Install & restart** behavior remain unchanged. Automatic checks do not install updates.

### Update

If you already use 0.4.3, choose **Branchline → Check for Updates…** and install this release inside the app.

For 0.4.2 or earlier, install an updater-enabled version once using the download below or the installer:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.

Validated with 158 Rust tests, 63 frontend tests, 11 offline installer checks, two release-manifest checks, and eight packaged MCP protocol checks.
