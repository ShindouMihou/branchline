Get a native alert when an AI request needs your review, and bring the right Branchline window forward reliably.

### Improvements

- Send a generic native OS notification for each new AI review request. Notification text contains no commands, repository names, paths, or source content.
- Open the matching request and repository window when a notification is clicked. Clicking a notification never approves or executes a command.
- Add a separate **Native notifications** control in Connections, enabled by default. Keep the existing auto-focus preference independent and preserve its saved value.
- Reactivate hidden macOS apps, restore minimized windows, and focus the matching repository window when automatic review opening is enabled.
- Remove the global ten-second focus throttle so closely spaced requests are not skipped. Repeated submissions of the same review remain silent.
- Allow an explicit native notification click to reopen a dismissed review, including when the request was previously shown.
- Allow background startup for notification-only configurations while still requiring an enabled connector and an authorized connection.

Notifications never grant approval. OS notification permissions and Focus/Do Not Disturb settings still control banner delivery. Review requests remain available in Branchline even when banners are suppressed.

### Update

Choose **Branchline → Check for Updates…**, then **Install & restart**. Automatic checks remain quiet unless an update is available.

For a fresh installation, or versions through 0.4.2:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies. macOS may request folder access again after installing a rebuilt preview.

Includes a live hidden-window review check and confirmation that macOS receives notifications. Publication is gated on the full Rust, frontend, offline installer, and release-manifest checks.
