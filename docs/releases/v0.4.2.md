Push approval previews now keep the remote and show each branch or tag destination, including atomic pushes.

### Fixes and improvements

- Fix missing remote and destination details when a push uses `--atomic`.
- Show separate rows for every supported branch, tag, or ref target, with branch and tag icons.
- Explain all-or-nothing updates and the requirement for server support.
- Preserve literal `HEAD` when an earlier command makes its branch uncertain.
- Keep a visible notice when some destinations require exact-command review.
- Continue loading older activity records without the new push metadata.

Command execution and whole-command approval behavior are unchanged. Previews do not verify remote state or guarantee a successful push.

### Install or update

Quit Branchline, then run:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

The installer verifies the archive checksum and app signature and installs to `~/Applications/Branchline.app` by default.

### Supported platform

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized. Normal macOS security policy applies; the installer does not bypass it.

Validated with 154 Rust tests, 56 frontend tests, 11 offline installer checks, and eight packaged MCP protocol checks.
