More reliable approval previews, clearer review stops, and smoother diff scrolling.

### Stable command previews

- Use a deterministic parsing work budget instead of a wall-clock deadline, so system load does not change which commands appear.
- Generate action cards and warnings from the same shell analysis.
- Keep whole-command approval and preview revalidation intact.

### Clearer review messages

- Explain the actual preview differences when approval stops: new or changed warnings, branch changes, file selections, PR descriptions, and execution context.
- Retain the explanation in the request and activity record instead of claiming the repository changed for every mismatch.
- Nothing executes from a stale request; ask the AI for a fresh request to review the changes.

### Smoother diff scrolling

- Contain sideways gestures and edge momentum inside the diff instead of letting the outer app move.
- Batch wheel updates once per animation frame and avoid repeated layout measurements during gestures.
- Preserve independent split-side scrolling, unified scrolling, native scrollbars, and vertical movement.
- Rebind AI review scroll controls after measuring their updated dimensions, and clean up pending work when panels are replaced.

### PR body-file support

- Show Markdown PR descriptions from `gh pr create --body-file PATH`, `--body-file=PATH`, and `-F PATH`.
- Support absolute temporary-file paths after shell guards, while retaining safe handling of relative paths.
- Read bounded regular UTF-8 files up to 64 KB; reject symbolic links and special files. Explain missing or unavailable descriptions.
- Recheck the current description at approval. It remains a file snapshot: earlier commands or later edits can change what GitHub CLI eventually reads.

### Update

Choose **Branchline → Check for Updates…**, then **Install & restart**. Automatic checks stay quiet unless an update is available.

For a fresh installation:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.

Validated with 212 Rust tests, 83 frontend tests, a 1,000-row browser diff with 150 contained scroll gestures, 8 MCP protocol cycles, 11 offline installer checks, 2 release-manifest checks, and the production build.
