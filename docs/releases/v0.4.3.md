Branchline can now check for new releases and install signed updates from inside the app.

### In-app updates

- Automatic update checks are enabled by default, at startup and at most once every six hours. They do not install anything automatically.
- Use **Branchline → Check for Updates…** or **Appearance → App updates** to check manually or change the preference.
- When a release is available, open the small **App update** button to review its notes and choose **Install & restart**.
- Download progress and concise status messages appear in a compact dialog with an aligned automatic-check switch.
- Update settings and progress are shared across repository windows. If Git or approved AI work is running, finish it and retry installation.

### Signed updates

Updates must come from this repository’s HTTPS release downloads, match the app’s embedded public key, and carry a signature bound to the announced version. Changed archives and mismatched versions are rejected. The release includes the signed updater archive, signature, and update manifest alongside the usual ZIP and checksum.

### One-time upgrade for existing users

Versions 0.4.2 and earlier do not contain the updater. Install 0.4.3 once using the download below or the usual installer; future releases can then be installed from inside Branchline. Quit Branchline before running the installer:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

The default destination is `~/Applications/Branchline.app`.

### Supported platform

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized. Normal macOS security policy still applies; neither installer bypasses it.

Validated with 158 Rust tests, 60 frontend tests, 11 offline installer checks, two release-manifest checks, and eight packaged MCP protocol checks. The signed archive was verified against the embedded public key, and a modified archive was rejected.
