Help your AI remember to use Branchline, and scroll through long source lines comfortably.

### Improvements

- Add an optional global instruction reminder during AI Skills setup and connector onboarding for detected default Codex and Claude Code profiles.
- Preview the exact reminder and destination before installation. Managed sections use clear start/end markers, preserve surrounding instructions, and include local backups and confirmed removal.
- Update previously opted-in, unchanged reminders when Branchline starts. Edited, unowned, or malformed sections stay untouched; removed sections are not silently restored.
- Keep reminder instructions focused on whole-command review, waiting for the actual result, and treating timeouts as pending rather than approval.
- Restore horizontal trackpad scrolling in whole-file previews. Split diffs also support horizontal gestures over either version in AI request reviews.

Instruction reminders guide the AI; they do not restrict separate terminal access. No global instructions are added until you opt in. Custom Codex profiles and profiles with AGENTS.override.md require manual integration.

### Update

Choose **Branchline → Check for Updates…** in an updater-enabled version and select **Install & restart**. Automatic checks stay quiet unless an update is available; installation is always your choice.

For a fresh installation, or versions through 0.4.2:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.

Validated with 167 Rust tests, 68 frontend tests, 11 offline installer checks, two release-manifest checks, and a browser check of horizontal scrolling.
