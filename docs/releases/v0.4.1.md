Release notes and pull request descriptions are now easier to read in Branchline.

### Improvements

- Render Markdown in release notes, pull request descriptions, and expanded AI explanations.
- Read headings, lists, tables, quotes, inline formatting, links, and fenced code blocks with styling that fits the dark interface.
- Open web links in your browser while keeping the approval screen in place.
- Keep exact commands and commit messages literal so the approved text remains clear.

### Privacy and safety

Raw HTML is escaped. Embedded images are shown as labels and do not load remote assets. Links are restricted to HTTP and HTTPS without embedded credentials, with validation in both the renderer and the native app.

### Install or update

Quit Branchline, then run:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

The installer downloads the latest release, verifies its checksum and app signature, and installs to `~/Applications/Branchline.app` by default.

### Supported platform

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized. Normal macOS security policy applies; the installer does not bypass it.

Validated with 147 Rust tests, 53 frontend tests, 11 offline installer checks, and eight packaged MCP protocol checks.
