A native macOS Git workspace and a visual permission gate for AI command workflows.

### Highlights

- Syntax-highlighted split/unified diffs, file and hunk staging, commits, history, and branch tools.
- Global MCP connections, whole-command approval, deny-with-reason, waiting for results, and local activity receipts.
- Clearer literal directory/configuration previews and structured repository-creation cards. Unknown file membership remains explicit.
- A one-line installer with SHA-256, app identity/signature checks, and replacement rollback.
- 146 Rust tests, 49 frontend tests, and 11 offline installer checks passing.

### Install

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

The default destination is ~/Applications/Branchline.app. Quit the GUI app before updating.

### Supported platform and preview limits

Apple Silicon macOS 12+. Intel, Windows, and Linux release builds are not provided. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies. The installer does not bypass it.

Approved commands run as your account. Process success is not independent proof of all effects. Detached or background work may outlive a shell timeout. See the connector guide for execution/privacy limits.
