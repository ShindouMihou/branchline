Follow approved commands as they run, and review Git actions clearly even when a request starts with checks or setup commands.

### Live command output

- Show live standard output and diagnostics in the native request and Activity views, with a scrollable console that preserves your position while you read.
- Keep the latest 128 KiB per stream for up to eight recent commands in app memory. Closing Branchline or clearing the associated activity removes this console history.
- Keep console text out of MCP responses, persisted receipts, exports, and Copy for AI. Command output may contain sensitive information; it is visible only in the native app session.
- Explain when no console output is available. Programs may buffer output or redirect it to log files; Branchline does not rewrite the approved command to intercept those files.

### Clearer command previews

- Use a pinned shell syntax parser to preserve recognizable Git and GitHub arguments after preparation commands, checks, environment assignments, and redirects.
- Recognize supported literal env, command, and sh -c wrappers. Mark conditional bodies, pipelines, and nested shell actions as possible actions rather than guaranteed execution.
- Add dedicated stash save/restore, rebase, and reset cards, including stash messages, untracked-file inclusion, literal rebase references, and reset modes.
- Keep dynamic messages and destinations explicitly unresolved. Never evaluate substitutions or infer file contents from the wrong repository or directory.
- Keep original failures distinct from later recovery requests. A successful recovery does not change the earlier request's recorded result.

Approval still covers the entire unchanged command. Structured cards describe requested arguments; arbitrary shell effects are not independently verified. Unsupported or runtime-dependent details remain visible as unknowns alongside the exact command.

### Update

Choose **Branchline → Check for Updates…**, then **Install & restart**. Automatic checks remain quiet unless an update is available.

For a fresh installation, or versions through 0.4.2:

```sh
curl -fsSL https://raw.githubusercontent.com/ShindouMihou/branchline/main/scripts/install.sh | bash
```

Quit Branchline before running the installer. Its default destination is `~/Applications/Branchline.app`.

Apple Silicon macOS 12 or later. This preview is ad-hoc signed and is not notarized; normal macOS security policy applies.
